☁ Sincronizar com o GitHub

Os dados são salvos num arquivo JSON dentro de um repositório privado seu. O token fica guardado só neste navegador, então é preciso conectar uma vez em cada aparelho.

Como criar o token (2 min)
  1. Crie um repositório privado, por exemplo painel-dados (pode marcar “Add a README”).
  2. Abra github.com/settings/personal-access-tokens/new (token fine-grained).
  3. Em Repository access, escolha Only select repositories e marque só o painel-dados.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Gere o token, copie e cole abaixo.
